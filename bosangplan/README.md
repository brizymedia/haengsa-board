# 셀비아 보상플랜 계산기

(주)비아블의 '셀비아' 보상플랜을 계산해 보는 프로그램입니다.
직급과 조직 실적을 넣으면 **한 기수(15일) 수당을 항목별로** 계산하고,
그 금액이 공정거래위원회가 공개한 **실제 판매원 56,117명 중 몇 등**인지 되짚어 줍니다.

"얼마 벌 수 있나"가 아니라 **"그 돈을 받으려면 몇 등이어야 하나"** 를 보는 도구입니다.

## 쓰는 법

브라우저에서 쓰기 — 파일을 더블클릭하면 바로 열립니다. 설치할 것 없습니다.

```
bosangplan/simulator.html
```

명령줄에서 쓰기 — 기본 시나리오 3개를 한 번에 보여줍니다.

```bash
cd bosangplan && python plan.py
```

조건을 직접 넣어 계산하기 — 디렉터 직급에 소실적 210만 CV, 추천분 44만 CV인 경우.

```bash
cd bosangplan && python plan.py --rank 디렉터 --weak 2100000 --referral 440000
```

결과를 JSON으로 받기 — 엑셀이나 다른 프로그램에 넘길 때 씁니다.

```bash
cd bosangplan && python plan.py --json
```

계산이 맞는지 확인하기 — 24항목을 검사합니다. 공시 수치 합계까지 검산합니다.

```bash
cd bosangplan && python tests.py
```

## 숫자의 출처 — 이 구분이 이 프로그램의 핵심입니다

| 표시 | 뜻 | 믿을 수 있는 정도 |
|---|---|---|
| `공시` | 공정거래위원회 사업자정보공개 (2025년도 실적) | 법정 공시. 확정 수치 |
| `규정` | (주)비아블 회원관리규정 (회사 홈페이지 공개분) | 회사 공식 문서 |
| `사업자` | 현직 사업자가 블로그에 공개한 내용 | 회사 확정치가 **아님** |
| `가정` | 공개된 근거가 없어 임의로 넣은 값 | **반드시 직접 확인할 것** |

회사 홈페이지의 마케팅플랜 페이지(`/Business/MarketPlan`)는 **회원 로그인을 해야 열립니다.**
그래서 수당 요율 일부는 확인이 불가능했고, 특히 **후원(바이너리)보너스 요율은 `가정`** 입니다.
추천인에게 공식 마케팅플랜을 받아 그 값을 바꿔 넣으셔야 실제와 맞는 계산이 됩니다.

## 확인된 핵심 수치 (2025년도 실적, 공정거래위원회 공시)

- 매출액 912.98억 원 (부가세 포함) · 업계 9위
- 후원수당 총액 316.48억 원 · **지급률 34.66%** (법정 상한 35%)
- 등록 판매원 56,117명 중 수당을 받은 사람 16,902명 (30.1%)
- **수당 0원 39,215명 (69.9%)** · 연 50만원 미만까지 합치면 91.8%
- 연 1억원 이상 41명 (0.07%) · 연 1천만원 이상 398명 (0.71%)
- 최근 3년 공정위 시정조치 내역 없음

## 계산에 깔린 전제

- 후원수당 총액은 총매출액의 **35%를 넘을 수 없고**, 넘으면 CAP이 걸려 전 회원 지급률이
  일괄 조정됩니다 (회원관리규정 제11조). 2025년 실제 지급률은 34.66%로 상한에 붙어 있습니다.
- 품위유지보너스는 **직급과 소실적을 동시에** 만족해야 합니다. 직급이 높아도 실적이
  아래 단계면 아래 단계 기준으로만 지급됩니다.
- 수당은 사업소득이라 3.3%가 원천징수되고, 구독 구매비용은 차감 전 금액입니다.
- 연환산은 24기수(월 2회 × 12개월) 기준이며, 그 실적이 1년 내내 유지된다는 가정입니다.
