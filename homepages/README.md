## 만드는 방식
- 틀: 우리 최근 납품물 **이에스컴퍼니(es-company)** 의 구조(다섯 페이지 · 문의 폼 · 사장님 수정 모드 · 검색 태그)를 이어받고, HD기획 · 프로이벤트 · 굿프랜드 · 큰길이벤트의 연출을 업체 분위기에 맞게 골라 씀. 업체마다 색 · 글꼴 · 대문 배치를 다르게.
- 기업형 범위라 **공지 · 게시판 · 자료실** 페이지를 추가.
- 사진: 각 업체 **본인 네이버 블로그의 현장 사진**만 사용(출처는 각 폴더 `assets/img/SOURCES.md`). 카톡 · 메일로 오는 원본을 받으면 교체.
- 히어로 영상: 업체 실제 사진으로 만든 천천히 움직이는 영상(AI 영상은 한글 간판을 뭉개서 안 씀 — 프로이벤트 작업 교훈).
- 시안이라 모든 페이지 검색 차단(noindex). 오픈할 때 푼다.
- 공통 지침: `_tools/BRIEF.md` · 도구: `_tools/*.py`
