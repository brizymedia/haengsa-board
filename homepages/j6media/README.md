## 사장님 직접 수정 모드

- 켜기: `사이트주소/?edit=j6-4212` (열쇠 **`j6-4212`**, 해시는 일곱 페이지 `<meta name="es-edit">`). 끄기: `?edit=off`. 열쇠가 틀리면 아무 표시도 안 난다.
- 글자(노란 점선)와 본문 사진을 누르면 고칠 수 있다. 레이아웃 · 색 · 순서는 못 건드린다. 공지 · 게시판 · 사진 목록 · 폼 · 마퀴 · 소개 문장(단어 점등)은 수정 대상에서 뺐다(공지는 `app.js` `NOTICES` 에서).
- 고친 것은 그 기기 브라우저(IndexedDB `j6-edit`)에 보관 → 「수정 내용 보내기」로 큰길브리지 문의 서버에 메일, 사진은 `제이식스미디어-수정요청-….json` 파일.
- 반영: `python tools/apply_edits.py 받은파일.json` → `git diff` 확인 → push.
