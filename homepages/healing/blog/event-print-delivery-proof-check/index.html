행사 인쇄물 납품 검수는 상자의 총개수만 세는 일이 아닙니다. 승인한 파일과 실제 도착한 물건을 연결해 확인합니다.

문구가 맞아도 크기와 묶음, 배포 대상이 다르면 현장에서 다시 나누는 작업이 생깁니다.

1. 행사 인쇄물 납품 검수 기준을 발주 전에 적습니다

안내 책자와 좌석 표지, 운영용 순서표는 쓰는 사람이 다릅니다. 발주 목록을 파일명만으로 적지 말고 품목 이름, 사용 위치, 배포 대상과 묶음 단위로 풀어 적습니다.

크기나 접는 방식처럼 실물에서 확인할 항목도 제작 담당과 합의합니다. 화면의 축소 보기만으로 실제 읽는 거리와 손에 드는 방식까지 확인했다고 처리하지 않습니다.

배포용과 내부 운영용을 같은 이름으로 부르지 않습니다. 외부에 나가면 안 되는 연락처나 내부 메모가 들어 있는 문서는 공개용 인쇄물과 목록 단계부터 구분합니다.

이 글은 문구의 내용과 표현을 만드는 안내가 아니라 승인 이후 실물의 일치 여부를 확인하는 안내입니다. 주최·후원 표기나 문구 검토는 제작 승인 전에 별도로 마쳐야 합니다.

2. 교정본에는 확인한 범위를 남깁니다

파일을 확인했다는 말은 글자를 읽었다는 뜻인지 실제 크기 견본을 봤다는 뜻인지 모호합니다. 검토자와 확인 범위를 나누어 적고 아직 검토하지 못한 항목은 그대로 남깁니다.

접지나 제본이 있는 물건은 펼친 화면뿐 아니라 실제 읽는 순서도 확인합니다. 표지와 뒷면, 안쪽 면이 의도한 방향인지 제작 담당이 제공하는 확인 방법으로 대조합니다.

최종 승인본은 납품 목록의 기준점입니다. 여러 수정 파일 중 어느 것을 제작했는지 연결할 수 있도록 파일명과 구분 표시를 기록하고 납품 담당과 공유합니다.

사진 속 의자에는 내빈석 표지가 놓여 있습니다. 사진에 보이는 표지를 참고하되 당시의 발주 수량이나 제작 검수 절차를 이 글에서 추정하지 않습니다.

3. 상자를 열면 품목부터 구분합니다

상자에 쓴 이름과 안에 든 종류를 대조합니다. 여러 품목이 함께 들어 있으면 각 품목의 실물 표본을 먼저 놓고 종류별로 분류한 뒤 수량을 확인합니다.

총수량이 맞아도 필요한 구역의 물건이 빠질 수 있습니다. 구역별 묶음 수량과 여분의 보관처를 따로 적어 어느 공간으로 보냈는지 연결합니다.

외관상 이상이 있는 물건은 정상 배포분과 섞지 않습니다. 접힘과 면 방향, 잘림처럼 확인할 차이는 담당자끼리 같은 기준으로 적고 사진 기록이 필요하면 물건의 문제 부분만 남깁니다.

수량 확인을 누가 마쳤는지 표시하고 아직 확인하지 않은 상자는 확인 대기로 둡니다. 다른 담당이 이미 확인했을 것이라고 생각해 전체 납품을 완료 상태로 올리지 않습니다.

4. 잘못 나온 묶음은 배포 전 분리합니다

오래된 장소명이나 변경 전 순서가 남은 인쇄물을 발견하면 어느 묶음에 같은 문제가 있는지 확인합니다. 눈에 띈 한 장만 치우고 나머지는 정상이라고 단정하지 않습니다.

같은 상자 안에 다른 버전이 섞여 있을 가능성도 제작 담당에게 확인합니다. 전량 확인이 필요한지, 구분 가능한 묶음이 있는지는 실제 납품 상태와 담당 판단에 따라 정합니다.

수정할 물건과 지금 쓸 물건은 물리적으로 나눕니다. 별도 보관 위치와 상태 표시를 두어 정리하던 사람이 다시 배포 상자로 합치지 않게 합니다.

현장에서 덧붙이는 수정 표시는 주최 측과 제작 담당이 읽기 가능성과 사용 조건을 확인한 뒤 적용합니다. 가리는 문구 때문에 다른 안내까지 숨겨지지 않는지 실물로 확인합니다.

5. 추가 제작은 기존 물건의 처리와 묶습니다

새 인쇄물을 요청할 때는 고친 파일만 보내지 말고 대체할 품목과 필요한 배포 구역을 함께 전달합니다. 이미 배포한 수량과 아직 보관 중인 수량이 다르면 대체 범위도 달라집니다.

추가 제작분을 받으면 새 물건이 도착했다는 사실과 이전 물건을 회수했다는 사실을 따로 확인합니다. 두 버전이 섞여 쓰이지 않도록 담당별 교체 위치를 기록합니다.

전체 재제작이 어려울 때 임의로 내용을 줄이거나 확인하지 않은 안내로 대체하지 않습니다. 주최 측 판단을 받아 사용할 수 있는 안내 수단과 아직 전달하지 못한 내용을 정리합니다.

현장 사진은 구조와 배치를 참고하는 자료입니다. 사진 속 표지와 현수막의 실제 원본을 이 글의 새 인쇄물로 복제하거나 원래 사진의 표기를 수정하지 않습니다.

6. 배포 담당에게는 완성 상태를 넘깁니다

배포할 품목의 이름과 수령 대상, 놓을 위치를 한 묶음에 적습니다. 여분을 누가 보관하는지도 함께 알려 다른 구역의 배포분을 승인 없이 가져가 쓰지 않도록 합니다.

인쇄물이 남았다는 이유만으로 현장 수요가 적었다고 결론 내리지 않습니다. 배포 위치에 도착했는지, 어느 묶음이 미배포인지 사실부터 확인하고 잔여품을 인계합니다.

실물 검수 결과는 제작 승인 기록과 함께 보관합니다. 문구 승인과 납품 확인이 서로 다른 단계임을 남겨 다음 담당이 파일 확인만 보고 배포 완료로 오해하지 않게 합니다.

공개 문구 자체를 검토하려면 안내판 문구 검수를 참고합니다. 제작물의 내용 확정과 실물 납품 대조를 순서대로 연결하면 확인 범위를 나누기 쉽습니다.
