1. 행사 배경음악 인계는 음악이 맡을 역할부터 씁니다

배경음악은 행사의 빈틈을 전부 소리로 채우기 위한 것이 아닙니다. 입장 대기, 순서 사이 전환, 쉬는 시간처럼 사용 장면을 나누고 음악이 필요 없는 구간도 표시합니다.

진행자가 안내를 읽거나 참가자가 질문하는 동안에는 말의 전달이 우선인지 주최 측과 합의합니다. 분위기를 유지해 달라는 추상적인 주문보다 어떤 목소리가 또렷하게 전달되어야 하는지 적는 편이 실행에 도움이 됩니다.

공연자가 동작에 맞춰 사용하는 음원은 별도 공연 큐시트로 관리합니다. 이 글은 출연자의 입장 신호나 자료 접수가 아니라 여러 순서 사이에 흐르는 음악의 운용 의도를 다룹니다.

곡 선택 단계에서는 행사 성격과 공개 이용 가능 범위를 확인합니다. 개인적으로 들을 수 있는 음악이라는 이유만으로 행사장 재생이나 편집까지 허용된 것으로 판단하지 않습니다.

2. 곡 목록 옆에 말과 음악의 관계를 적습니다

낮추기와 끄기, 일시정지는 서로 다른 지시입니다. 작게 계속 들리게 할지, 완전히 끝낼지, 잠깐 멈췄다가 이어갈지를 말로 구분하고 운영석이 이해한 내용을 되읽게 합니다.

사용 장면말이 시작될 때말이 끝난 뒤미리 들을 부분
입장 대기안내가 들리도록 조정대기 음악 유지 여부 확인반복 연결 부분
순서 전환소개 전 종료 또는 낮추기다음 순서로 넘김끝부분의 여운
쉬는 시간호출 방송에 맞춰 조정합의한 대기 상태 복귀음악과 방송의 관계
마무리 안내귀가 안내를 우선 전달종료 판단 뒤 정리마지막 소리가 끝나는 지점

표의 지시는 예시이므로 실제 행사에서는 음향 담당과 가능한 조작을 맞춥니다. 음량 수치나 조절 장치의 위치를 주최 측이 임의로 정하기보다 객석에서 말과 음악이 어떻게 들리는지 확인합니다.

사진의 화면과 객석 배치는 안내가 전달되는 공간을 참고하기 위한 것입니다. 사진에서 들리지 않는 음악의 종류나 실제 음향 조정 상태를 추정하지 않습니다.

3. 반복 구간과 끝내는 지점을 귀로 확인합니다

처음 몇 초만 듣고 대기용으로 적합하다고 정하지 않습니다. 곡 중간에 말소리, 갑작스러운 변화, 긴 무음이 있는지와 끝에서 다시 처음으로 넘어갈 때 어떻게 들리는지 확인합니다.

반복이 필요한 장면이라도 곡 전체 반복과 특정 구간 반복은 결과가 다릅니다. 반복 구간을 바꾸거나 편집본을 만들 필요가 있다면 자료 제공자와 이용 범위, 작업 담당을 먼저 확인합니다.

곡의 끝과 순서의 끝이 같다고 가정하지 않습니다. 대기가 길어질 때 계속 재생할지, 조용히 기다릴지 정하고 담당자가 새 곡을 즉석에서 선택해야 하는 상황을 줄입니다.

전환 음악은 마지막 소리까지 들려준 뒤 다음 말을 시작할지, 합의한 지점에서 줄일지 표시합니다. 음악을 끊는 동작과 다음 마이크를 여는 동작이 엇갈리지 않도록 연결 구간을 함께 들어 봅니다.

4. 버전이 바뀌면 조작 결과도 다시 확인합니다

같은 곡의 보컬 버전과 연주 버전, 짧은 편집본은 서로 대체 가능한 자료로 보지 않습니다. 승인한 버전의 식별 정보와 실제 재생 목록의 항목을 연결하고 무엇이 달라졌는지 남깁니다.

버전을 교체하면 시작 지점, 반복 구간, 끝내는 방식이 그대로 유효한지 확인합니다. 이전 버전에 붙인 조작 메모를 새 파일에 복사하는 것만으로 인계가 끝나지 않습니다.

대체곡은 원곡과 비슷한 분위기라는 이유만으로 자동 사용하지 않습니다. 사용할 수 있는 장면과 내용 확인 상태를 적고, 답을 받지 못한 경우에는 음악 없이 진행하는 선택도 주최 측과 검토합니다.

음원이 들어 있는 기기와 실제 출력 경로의 점검은 음향 담당에게 확인합니다. 주최 측 담당자가 행사 중 케이블을 바꾸거나 장비 설정을 임의로 조작하는 방식은 피합니다.

5. 중단과 교대 때는 현재 재생 상태를 넘깁니다

중단 뒤에는 이어 틀기와 처음부터 재생하기를 다시 구분합니다. 안내 때문에 멈춘 곡을 자동으로 이어 틀면 이미 다른 순서가 시작된 뒤 음악이 겹칠 수 있습니다.

교대하는 사람에게는 지금 들리는 곡, 다음에 준비한 곡, 반복 여부, 마지막으로 받은 지시를 알려 줍니다. 파일 목록만 전달하면 현재 어느 장면인지 새 담당이 추측하게 됩니다.

새 담당은 조작을 넘겨받기 전에 현재 상태를 말로 확인합니다. 교대 직후 첫 전환은 기존 담당이 가능하면 함께 확인하고, 불확실한 지시는 주최 측 연락 창구로 다시 묻습니다.

원치 않는 음악이나 이상한 소리가 나오면 즉석에서 다른 곡을 겹쳐 틀어 가리지 않습니다. 음향 담당이 상태를 확인하고 진행자는 합의한 안내를 이어가도록 역할을 나눕니다.

6. 상담에는 선곡보다 사용 장면을 먼저 전합니다

선곡, 음원 편집, 재생 기기 준비가 어디까지 포함되는지는 각각 확인합니다. 특정 음악 이용이나 모든 버전의 현장 변환을 요청 범위에 자동으로 넣지 않습니다.

자동 견적서에서 필요한 진행·음향 항목을 살펴보고 견적 문의에 음악이 필요한 순서와 말이 겹치는 구간을 전달합니다. 결정하지 못한 재개 방식은 질문으로 남깁니다.

출연팀의 준비 상태와 무대 입장 신호는 공연 큐시트, 화면 자료의 취합은 발표자료 확인표로 분리합니다. 음악 운용표에는 같은 파일을 언제 어떻게 들려줄지만 명확히 남깁니다.
