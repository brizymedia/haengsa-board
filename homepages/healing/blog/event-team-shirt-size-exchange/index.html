행사 단체복 배부: 크기 선택·교환·미수령 구분

읽는 시간 약 5분

행사 단체복 배부는 받을 사람, 받을 종류, 실제 받은 상태를 따로 확인하는 것이 핵심입니다. 크기 변경을 종이 한쪽에만 적으면 물품 수량과 수령 기록이 어긋나므로 교환 흐름까지 함께 준비합니다.

이 글의 요점
  • 색상과 크기, 물품 종류를 각각 읽을 수 있게 분류합니다.
  • 신청한 크기와 현재 받는 크기를 구분해서 기록합니다.
  • 교환 조건은 주최 측이 확정한 범위만 안내합니다.
  • 미수령품과 교환 확인 대기 물품을 따로 보관합니다.

1. 행사 단체복 배부 목록을 물품 기준으로 나눕니다

팀 이름만 적힌 목록에서는 같은 팀의 크기별 물품을 고르기 어렵습니다. 물품 종류, 색상, 표시된 크기를 함께 적고 봉투 밖에서도 내용을 확인할 수 있는 분류표를 만듭니다.

같은 크기 표기라도 다른 제품이라면 같은 착용감이라고 단정하지 않습니다. 실제 준비된 제품의 표기와 주최 측이 안내한 선택 정보를 대조하고, 담당자의 감으로 특정 크기를 권하지 않습니다.

사전 신청을 받았다면 신청 기록은 선택의 출발점으로 둡니다. 현장에서 다른 크기를 받게 되는 경우를 기록할 칸이 있어야 원래 신청과 실제 배부의 차이를 나중에 설명할 수 있습니다.

2. 수령 확인과 크기 변경을 한 줄에서 읽습니다

배부 창구에서는 이름을 확인하는 일과 상자에서 물품을 꺼내는 일을 연결합니다. 한 사람이 여러 명의 물품을 대신 받는 경우에는 누구의 물품을 가져갔는지 나눠 적어 각각 수령했는지 확인합니다.

확인 단계기록할 것구분할 상태
수령 전신청한 종류·색·크기아직 받지 않음
실제 배부실제로 나간 종류·색·크기수령 완료
교환 요청돌려준 물품과 원하는 물품확인 대기
교환 완료회수품·새 배부품 대조기록 갱신 완료

표의 단계는 담당자가 함께 읽는 예시입니다. 불필요한 신체 정보까지 적기보다 물품 표기와 실제 이동을 기록하고, 참가자에게 보여 주는 명단에는 다른 사람의 선택이 드러나지 않게 합니다.

3. 같은 색 다른 크기를 손이 가는 위치에서 구별합니다

크기가 다른 봉투를 한 상자에 넣을 때는 겉면 표식을 같은 방향으로 둡니다. 큰 글씨의 팀 이름만 보이고 작은 크기 표시가 가려지면 창구가 바쁠 때 서로 다른 물품을 집기 쉽습니다.

탁자 위에 보여 주는 확인용 물품이 있다면 배부용과 구분합니다. 참가자가 직접 가져가도 되는 물품과 담당자가 확인 후 건네는 물품을 같은 표식으로 놓지 않는 것이 좋습니다.

묶음째 다른 창구로 넘길 때도 종류와 크기 구성을 적습니다. 단순히 상자 하나를 보냈다고 기록하면 받는 곳은 어떤 물품이 줄고 늘었는지 알 수 없으므로 양쪽 분류를 맞춥니다.

4. 교환은 가능한 조건과 확인 창구를 먼저 정합니다

남은 물품이 있다고 모든 교환을 약속하지 않습니다. 개봉·사용 여부나 회수 상태를 어떻게 볼지는 주최 측과 공급 조건을 확인해야 하며, 창구 담당이 참가자마다 다른 기준을 만들지 않도록 합니다.

교환 요청을 받으면 돌려준 물품과 새로 나가는 물품을 함께 확인합니다. 새 물품만 수량에서 빼고 회수품의 상태를 기록하지 않으면 다시 배부할 수 없는 물품까지 사용 가능한 재고로 남을 수 있습니다.

원하는 크기가 없을 때는 대기, 다른 선택, 미배부 중 주최 측이 정한 방법을 안내합니다. 추후 확보가 확인되지 않았는데 나중에 반드시 보내 준다고 약속하지 않습니다.

5. 미수령품과 확인 대기품을 한곳에 섞지 않습니다

미수령품은 아직 나가지 않은 물품이고, 교환 확인 대기품은 돌려받았지만 상태 판단이 끝나지 않은 물품입니다. 두 종류를 함께 놓으면 담당자가 모두 배부 가능한 것으로 읽을 수 있습니다.

행사 중간에 남은 수량을 셀 때는 배부 가능품부터 확인합니다. 확인 대기품이나 전시용 물품을 합계에 넣었다면 그 구성을 분명히 적어야 다른 창구가 잘못된 수량을 기준으로 안내하지 않습니다.

종료 뒤 남은 물품의 인계 대상을 정합니다. 미수령자의 이름을 공개 게시하기보다 정해 둔 창구에서 본인 물품을 확인하도록 안내하고, 이후 전달 방식이 미정이면 확정 후 따로 알린다고 구분하세요.

6. 단체복 업무와 행사 진행 협의를 분리합니다

팀 색상을 진행 안내에 사용할 계획이라면 실제 지급 상태와 색 구분의 어려움을 함께 확인하세요. 옷을 받지 못했거나 갈아입지 않는 참가자도 자기 팀을 알 수 있도록 이름이나 다른 표식을 병행할지 정합니다.

자동 견적서와 견적 문의에 프로그램과 팀 구분 방식을 전달하세요. 단체복 배부가 끝나야만 다음 순서를 시작할 수 있는지, 미수령자는 어디에서 합류하는지 주최 측 조건을 따로 적습니다.

크기를 바꾸면 원래 신청 기록을 지우나요?

원래 신청과 실제 배부를 구분해 남깁니다. 변경 이유를 길게 적기보다 현재 어떤 물품을 받았는지 확인할 수 있게 기록하세요.

돌려받은 옷은 바로 다시 배부하나요?

주최 측이 정한 교환 조건과 물품 상태 확인이 먼저입니다. 판단이 끝나기 전에는 배부 가능한 물품과 섞지 않습니다.

단체복이 없는 사람은 팀 게임에 못 들어가나요?

옷만으로 팀을 식별하지 않도록 다른 표식을 함께 검토합니다. 실제 참여 방식은 프로그램과 참가자 조건에 맞추어 사전에 협의할 일입니다.
