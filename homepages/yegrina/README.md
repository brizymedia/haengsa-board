## 굿프랜드와 다르게 만든 스크롤 연출

굿프랜드(같은 유아체육 업종)의 「스크롤에 반응하는」 느낌은 이어받되 장치는 새로 만들었다.
| 굿프랜드 | 예그리나 |
|---|---|
| 상단 진행률 막대 | 헤더 밑 **만국기 줄 + 노란 공**이 굴러가는 진행 표시 |
| 히어로 영상 확대 · 흐림 | 영상이 **둥근 액자**에 들어 있고 스크롤하면 액자가 뒤로 물러남, 제목 글자가 **통통 튀며** 등장 |
| 프로그램 가로 스크롤 | 세 가지 일 **쌓이는 카드**(뒤 카드가 올라오면 앞 카드가 작아짐) |
| 숫자 카운트업 | 숫자가 든 **공이 떨어져 튀는** 카운트업 |
| 연도 고정 표시 | 연혁 **트랙이 차오르며** 지난 해에 불이 켜짐 |
| 단어 점등 · 마퀴 | 행사 종류 띠, **문의 시기 트랙**(6개월 전 → 행사일), 자격 칩 팝인, 문의 띠 색종이 |

`prefers-reduced-motion` 이면 전부 멈추고 히어로는 포스터만 보인다.
